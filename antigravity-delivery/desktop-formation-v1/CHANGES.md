# 變更清單與技術方法說明 (CHANGES.md)

本文件說明 Antigravity 在 `E:\占卜\antigravity-delivery\desktop-formation-v1` 中交付模組之架構變更、技術實現方法、使用者回饋修訂、授權來源與已知限制。

---

## 1. 模組拆分與架構變更 (Architectural Changes)

1. **從原型動漫互動中徹底解耦**：
   - 移除了原 `E:\占卜\app.js` 與 `divination.js` 中的隨機心念雜湊排盤、籤詩庫、角色語錄、吉凶計分演算法及動漫人物名稱。
   - 完全採用 `chart-types.ts` 定義之真實奇門遁甲資料模型，由外部 `setChart(chart)` 或 `play(chart)` 傳入。
2. **遵守 `scene-contract.ts` 固定呈現接口**：
   - 匯出單一入口函式 `mountQimenFormation(host, options)`，回傳 `{ setChart, play, skip, selectPalace, setReducedMotion, destroy }`。
   - 所有 DOM 限制於 `host` 容器內部，樣式以 `.qm-scene` 前綴嚴密隔離，不污染外部全域 DOM、路由或表單。
3. **時序與階段精確對齊**：
   - 嚴格實作 6 秒時序：`center` (0-600ms) → `expand` (600-1400ms) → `directions` (1400-4800ms，八方 9→2→7→6→1→8→3→4 各 420ms) → `resonance` (4800-5100ms) → `complete` (5100-5800ms) → departure (5800-6000ms) → `interactive` (6000ms+)。
   - 支援 `skip()` 與 `prefers-reduced-motion`，能立即跳過或靜態呈現，絕不留下孤立未決定的 Promise。

## 2. 徹底解決九宮格遮擋問題 (Zero Occlusion Architecture)

針對使用者反饋「我看不到，被九宮格擋住了」之解決方案：

1. **動畫期（0–5.8s）全屏沉浸無遮蔽**：在中心凝聚、向外展環、八方啟動與全盤共鳴期間，右側九宮格面板徹底淡出並移出可視區（`opacity: 0; pointer-events: none`），3D 法陣享有 100% 全屏無遮蔽的沉浸式震撼視野。
2. **底部電影級字幕橫幅**：將階段說明與方位提示（如「【八方啟動】 坎宮（第 1 宮 · 北）· 休門位啟動 · 沖天靈光」）移至畫面最底部居中，完全不遮擋中宮太極、道者身形與內外盤環。
3. **互動作盤側欄並列與一鍵收合**：局成與作盤模式下，九宮格以半透明黑金毛玻璃質感停靠於右側（寬度約 35%），左側 65% 為清晰運行的 3D 法陣；並在面板頂部新增「`◫ 收合面板`」按鈕，使用者隨時可一鍵收合側欄，享受全幅無邊界 3D 法陣。

## 3. 極致空間感與 3D 運鏡重構 (3D Spatial Depth & Camera Dynamics)

針對使用者反饋「沒有空間感，感覺還有提升空間」之解決方案：

1. **多層浮空階梯立體高度 (Multi-tier Vertical Levitation)**：
   法陣各盤不再平面疊合於地面，而是依天體渾天儀構造分配真實立體高度：
   * 地面九宮方格網：`y = 0`，帶有浮空法盤的地面暗調投影陰影（Ambient Occlusion Drop Shadows）。
   * 中宮太極核心與道者站立：`y = -4`。
   * 洛書九宮數環：`y = -14`。
   * 後天八卦爻象盤：`y = -28`。
   * 人盤八門環：`y = -48`。
   * 天盤九星環：`y = -70`。
   * 神盤八神環：`y = -94`。
   * 外周天二十八宿周天環：`y = -120`（高懸於星穹穹頂）。
   * **星索天柱立體骨架**：八方軸線上，自地面 `y = 0` 向上貫穿至 `y = -120` 的金色立柱光索，營造立體渾天儀之精準力學縱深。
2. **電影級動態相機運鏡 (Cinematic Camera Trajectory)**：
   * `0 - 600ms`（踏定中宮）：低角度英雄近景（`pitch = 44°`, `distance = 540`），足踏瞬間激發相機衝擊微震（Camera Shake/Trauma Decay）。
   * `600 - 1400ms`（四盤展環）：相機流暢向後拉遠並抬升視角（`distance: 540 -> 710`, `pitch: 44° -> 55°`），呈現多層法環拔地而起、浮空舒展的震撼宏偉感。
   * `1400 - 4800ms`（八方啟動）：相機進行天體天平微搖巡航（`yaw ±0.038 rad`, `pitch ±1.5°`），各層盤環之間產生強烈真實立體動態視差（Motion Parallax）。
   * `4800 - 5100ms`（全盤共鳴）：八方沖天光柱暴漲至高空（`y = -400`），激發全陣高頻共振微震。
   * `5100 - 6000ms`（局成）：相機平穩歸位至典雅俯瞰視角。
3. **實時滑鼠 3D 視差與自由軌道旋轉互動**：
   * 滑鼠游標掠過畫布時，相機俯仰（Pitch）與航向（Yaw）即時進行物理阻尼微傾斜，立體層次一目了然。
   * 支援按住滑鼠左鍵 360° 自由環視旋轉、滾輪縮放視角距離、雙擊重置視角。
   * 支援直接點擊畫布上的 3D 落宮選宮。

針對使用者反饋「每次動畫都一樣」之解決方案：

1. **陰陽遁旋轉方向與能量色調徹底分化**：
   * **陽遁（Yang Dun）**：順行周天旋轉（順時針流轉），以太陽暖金為主能量，噴發金火靈氣粒子。

2. **局數動量與角速度差異**：
   * 根據傳入真盤之局數 `facts.ju`（1~9）與時柱，決定初期四盤撥動之爆發初速度與阻尼曲線，每一局之轉速、慣性與過渡節奏皆具有獨特性。
3. **真盤符號精確入盤（非固定硬編碼）**：
   * 人盤、天盤、神盤於 5100ms「局成」瞬間，精準將傳入 `chart.palaces` 該盤專屬之八門、九星、八神、天盤奇儀、地盤奇儀鎖定於真實落宮方位。
   * 值符、值使所在之宮位具有專屬金色光環與光柱加強標記。
   * 切換四份真盤樣本（陽遁正常、陰遁正常、陽遁中宮、陰遁中宮）時，旋轉方向、速度感、盤上字樣與光柱標記皆截然不同！

## 5. 局成常態活局主循環 (Living Idle Formation Loop - 徹底解決「動畫結束後就不動了」)

針對使用者回饋「動畫結束後就不動了」之重大架構升級：

1. **常態活局渲染引擎 (Continuous Interactive Render Loop)**：
   * 原架構於 6 秒動畫結算 (`concludeAnimation`) 或 `skip()` 之後便立即取消 rAF 循環，導致陣法如同靜態死圖。
   * 新架構在 `play()` 承諾（Promise）結算後，無縫銜接至 `startIdleLoop()`，維持輕量 60 FPS 活局運算（CPU 開銷 < 1ms/frame）：
     - **太極陰陽雙魚道法長轉**：太極雙魚在局成後保持悠長仙氣慢速呼吸旋轉（陽遁順轉、陰遁逆轉，每秒約 0.6 弧度），陰陽二氣生生不息。
     - **多層浮空階梯天體歲差與呼吸微浮**：天盤九星、神盤八神、後天八卦與外周天二十八宿在 $y = 0 \sim -120$ 階梯高度上帶有彼此錯相的立體浮空律動（`floatPulse`），二十八宿星輪帶有慢速周天漂移與星光明滅閃爍。
     - **靈氣金屑與青焰升騰生生不息**：60 顆空間靈氣微粒（`ambientParticles`）持續從地面生成、穿透各層法環緩緩升空飄逸並回圈循環，陣中始終充盈天地元氣。
     - **值符星與值使門之長明靈柱 (Eternal Duty Beacons)**：局成後保留值符與值使宮位之通天半透明光柱，帶有正弦波溫潤呼吸起伏，標示當前時辰天地樞紐。
     - **選中宮位之 3D 聚光與地脈共鳴**：使用者在九宮格或 3D 畫布上點選宮位時，該宮位地面立即激發金色衝擊波與靈氣火星，並常駐專屬聚光天柱與地面擴散光環。
     - **實時無延遲 3D 滑鼠視差與軌道拖曳**：滑鼠掠過畫布時，相機俯仰（Pitch）與偏航（Yaw）即時進行物理阻尼微傾斜；按住左鍵 360° 旋轉隨手即動；滾輪縮放無段平滑推拉。
2. **嚴密資源與節能管理 (Eco-friendly Lifecycle)**：
   * 分頁切換至後台（`document.hidden`）或啟用 `prefers-reduced-motion` 時，自動暫停 idle loop，避免背景 CPU/GPU 資源浪費。
   * 調用 `destroy()` 時徹底釋放 `cancelAnimationFrame(idleRafId)`、清除事件監聽與畫布，保證零記憶體洩漏與重複掛載安全性。
