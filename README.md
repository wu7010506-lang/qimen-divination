# 奇門遁甲 · 風後奇門占卜堂 (Feng Hou Qi Men Divination Platform)

以「風後奇門」體系為核心，參考現代主流占卜網站（塔羅牌、易經占卜、奇門遁甲排盤、六爻、道家靈籤），所打造的 **3D 沉浸式互動算局占卜平台**。

---

## ⛩️ 占卜網站核心參考與設計理念

相較於傳統塔羅或單純排盤工具，本系統融合了：
1. **「一事一問，立心中宮」的儀式感**（參考專業占卜如 OpenFate、FateMaster、Labyrinthos）：
   - 使用者在問卜殿堂專注輸入問題（或選取事業、感情、財富、抉擇、身心、今日一局）。
   - 點擊「踏定中宮 · 運籌起局」時，中央太極以衝擊波與低音重擊震盪，立定中宮「我即是方位，我即是吉凶」。
2. **四盤立體流轉與定宮顯化（天地人神四維拆解）**：
   - **地盤八卦宮位（地利）**：分析客觀現實基礎、環境五行屬性。
   - **人盤八門（人和）**：開、休、生、傷、杜、景、死、驚，指示人事行動、機遇與阻礙。
   - **天盤九星（天時）**：天蓬、天任、天沖、天輔、天英、天芮、天柱、天心，代表大勢走向與時機。
   - **神盤八神（神助）**：值符、螣蛇、太陰、六合、白虎、玄武、九地、九天，指引第六感、隱藏機運與潛在威脅。
3. **經典道家哲學箴言**：
   - 秉持道家超然隨性與通透視角，給予使用者直擊痛處卻又溫暖豁達的人生建言。
4. **風後奇門 · 破局之策（逆轉局勢心法）**：
   - 傳統算命常給予宿命論的吉凶定論，而風後奇門的真諦在於「撥動四盤，趨吉避凶」。
   - 每張解盤卷軸皆附贈：**利好方位**、**行事策略**、**調心心法**。
5. **歷史紀錄與結緣籤卡分享**：
   - 支援本機儲存（LocalStorage）過往 20 筆占卜紀錄，隨時複盤覆核。
   - 一鍵複製「占卜結緣摘要」文本，方便分享給好友或記錄日記。

## 🎮 操作指引

| 鍵位 / 按鈕 | 功能說明 |
| :--- | :--- |
| **頂部「起局求策」/ [卜] 按鈕** | 開啟問卜殿堂，選擇分類並輸入想占卜的疑難 |
| **空白鍵 [Space] 或「踩下中宮」** | 直接在 3D 空間踩定中宮、展開或收回法陣 |
| **頂部「占卜紀錄」** | 查看過往問卜紀錄與卦象摘要 |
| **滑鼠左鍵拖曳** | 旋轉 3D 空間視角（仰角與環視） |
| **滑鼠滾輪** | 放大 / 縮小法陣距離 |
| **右側「3D 傾角」** | 切換 3D 斜俯角或正俯瞰羅盤平面視角 |
| **右側「巡航運轉」** | 開啟 3D 相機圍繞陣盤自動巡航旋轉 |
| **右側「音效」** | 開啟 / 靜音原生合成道術音效 (Web Audio API) |
